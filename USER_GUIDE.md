# Руководство пользователя AVIS

## Запуск

Дважды щёлкните `Avis.App.exe` в папке `dist\AVIS`. Ничего устанавливать не нужно:
рядом лежат `shared\` и `models\`, приложение само их найдёт.

При старте AVIS выбирает нейро-источник, если в `models\v1` есть `model.onnx`,
иначе DSP. Захват идёт с устройства вывода Windows по умолчанию (WASAPI loopback).

## Окно

- **Верхняя панель**: переключатель источника, пауза, настройки, снимок.
- **Сцена**: объекты — пятна, положение по X зависит от панорамы, по Y — от частоты,
  размер и яркость — от громкости, цвет — от тембра или палитры.
- **Статус-строка**: FPS, задержка анализа, число объектов, устройство.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F11` | войти/выйти из полноэкранного оверлея |
| `Esc` | выйти из оверлея |
| `F12` | сохранить снимок в `artifacts\app` (или рядом с exe) |
| `Space` | пауза/продолжить |

В оверлее окно становится «сквозным» для мыши и поверх всех окон — удобно поверх
плеера или браузера.

## Настройки

Панель настроек открывается кнопкой с шестерёнкой. Все параметры сгруппированы:

- **capture** — устройство, усиление (дБ).
- **analysis** — диапазон частот, шкала (log/erb/mel/linear), порог активности,
  максимальное число объектов, параметры трекера.
- **visual** — режим Y (абсолютный/партиалы/салиентность), громкость, гамма,
  размер и мягкость сплатов, bloom, сглаживание, атака/релиз, барабаны,
  аккорды (per-note/elongated), шлейфы/водопад, видимость шума, цвет (палитра/тембр),
  прозрачность.
- **window** — Mica/Acrylic, поверх всех окон, оверлей.
- **debug** — вид (main/spectro/masks/table/embedding), статистика, запись JSONL.
- **model** — имя модели, провайдер (CPU/DirectML).

Пресеты: **Сбалансированный**, **Спокойный**, **Яркий**, **Тёмный**, **Отладка**.
Пресет заменяет все настройки; свои изменения сохраняются при выходе в
`%LOCALAPPDATA%\AVIS\settings.json`.

## Источники

- **Neural** — модель M-v1, лучшее разделение инструментов. Требует `models\v1`.
- **DSP** — спектральные партиалы и гармонические группы, без модели; работает всегда.
- **Mock** — синтетические объекты для проверки рендера и FPS.

## Снимки и запись

- Кнопка «Снимок» или `F12` пишет PNG.
- В настройках можно включить запись JSONL — поток кадров с объектами для
  офлайн-анализа и отладки (`avis-cli render/check`).

## Командная строка

```
Avis.App.exe [--source mock|dsp|neural] [--bench <сек>] [--bench-out <json>]
             [--autoclose] [--set group.name=value] [--screenshot <png>]
             [--screenshot-at <сек>] [--overlay] [--topmost]
             [--model <путь|имя>] [--wav <файл>]
```

Примеры:

```powershell
# 10 секунд mock-бенчмарка и авто-закрытие
Avis.App.exe --source mock --bench 10 --bench-out bench.json --autoclose

# скриншот нейро-режима на 5-й секунде WAV
Avis.App.exe --source neural --wav test.wav --screenshot shot.png --screenshot-at 5 --autoclose

# изменить параметр визуала
Avis.App.exe --set visual.splatSize=2 --set visual.bloom=0.2
```

`--wav` — дополнительная возможность для тестов без loopback: файл проигрывается
в реальном времени и подаётся в тот же фронтенд.
