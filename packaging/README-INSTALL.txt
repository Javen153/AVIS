AVIS 1.0.0 — установка (Windows 10 19041+ / Windows 11, x64)
==========================================================

В архиве лежит готовая программа: .NET и Windows App SDK уже внутри,
доустанавливать ничего не нужно.

ВАРИАНТ 1. Установка (ярлыки на рабочем столе и в меню «Пуск»)
--------------------------------------------------------------
1. Распакуйте архив целиком в любую папку (например, в Загрузки).
2. Откройте PowerShell в этой папке и выполните:

   powershell -ExecutionPolicy Bypass -File install.ps1

   Программа скопируется в %LOCALAPPDATA%\Programs\AVIS, появятся ярлыки AVIS.
   Другой путь: -Dir "D:\Apps\AVIS". Без ярлыков: -NoShortcuts.

3. Запустите AVIS ярлыком или файлом Avis.App.exe.

ВАРИАНТ 2. Без установки (portable)
-----------------------------------
Запустите Avis.App.exe прямо из распакованной папки. Настройки хранятся
в профиле пользователя, поэтому папку можно переносить.

УДАЛЕНИЕ
--------
   powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall

Настройки пользователя при удалении сохраняются.

ПЕРВЫЙ ЗАПУСК
-------------
- Источник по умолчанию — DSP (без нейросети). Переключите «Источник» на
  Neural, чтобы включить модель.
- В «Настройки → Нейросеть → Модель» доступны версии v1, v2.1, v3, v3_1,
  v3_2, v3_3. По умолчанию выбрана v1 — эталонная модель.
- Захват идёт через WASAPI loopback: включите музыку в любом плеере.
- F11 — полноэкранный режим, Esc — выход из него.

ЕСЛИ WINDOWS ПОКАЗЫВАЕТ ПРЕДУПРЕЖДЕНИЕ
---------------------------------------
Файл не подписан сертификатом. В окне SmartScreen нажмите «Подробнее» →
«Выполнить в любом случае». Это обычное поведение для неподписанных сборок.
